# Support

If you encounter any issues or have questions about SimpleAudioBookGen, please follow the guidelines below.

## How to Report a Bug
To help us resolve the issue quickly, please provide the following information when opening a GitHub Issue:

1.  **Windows Version:** (e.g., Windows 10, Windows 11)
2.  **App Version:** (e.g., 0.1.0-beta)
3.  **Voice Mode Used:** (e.g., Natural Online, Offline Neural, etc.)
4.  **PDF Type:** (Was it a text-based PDF or a scanned image PDF?)
5.  **Error Message:** Please copy and paste any error message shown in the UI or in the `audiobook_gen.log` file.
6.  **Steps to Reproduce:** What were you doing when the error occurred?

## Frequently Asked Questions

### Why is the conversion taking so long?
Long PDFs or high-quality offline voices (like Kokoro) require significant processing power. Scanned PDFs requiring OCR will also take much longer than text-based PDFs.

### Why is "Natural Online" voice not working?
This mode requires an active internet connection. Please check your connectivity.

### How do I install offline voices?
Please refer to the `README.md` or `MANUAL_VOICES.md` for instructions on downloading and placing model files for Kokoro or Piper.

## Privacy Warning
**Do not upload private or sensitive PDF files** to GitHub Issues. Only provide technical details or sample files that do not contain personal information.
